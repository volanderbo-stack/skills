# Як користуватися проєктом

Усі правила для Claude вже записані в `CLAUDE.md`, тож у чаті достатньо коротко сказати, що потрібно.

## 1. Покладіть матеріали
- `assets/` — відео, фото, скріншоти, музика, транскрипти (`.srt`).
- `assets/brand/` — лого, кольори (можна просто `кольори.txt`), файли шрифтів.

Ці файли Claude тільки читає й ніколи не змінює.

## 2. Напишіть команду

| Команда | Що робить | Приклад |
|---|---|---|
| `/idea` | Лише придумати 3 ідеї й спитати, яка підходить | `/idea відео для Instagram про Копійку` або просто `/idea` |
| `/promo` | Хайп-промо на 12–20 с | `/promo застосунок Копійка — облік витрат за 10 секунд, сайт kopiyka.app, 9:16` |
| `/motion` | Коротка графіка до 30 с: титри, цифри, лого, плашка з підписом | `/motion лого-заставка 3 с з лого з assets/brand/logo.svg` |
| `/broll` | Motion-вставки під відео з людиною | `/broll assets/interview.mp4 assets/interview.srt` |
| `/sfx` | Звукові ефекти й музика під готове відео | `/sfx output/2026-10-22-promo-kopiyka.mp4 підбери музику, для Instagram` |
| `/subtitles` | Анімовані субтитри | `/subtitles assets/reel.mp4 жовте підсвічування слова` |
| `/video` | Будь-що інше, Claude сам обере інструмент | `/video пояснювальний ролик на 60 с про те, як працює кешбек` |
| `/script` | Лише сценарій і розкадровка, без рендеру, щоб ви погодили | `/script промо Копійки на 30 с для Instagram, з голосом` |

Можна писати й без команди, звичайним текстом: Claude обере інструмент за правилами з `CLAUDE.md`.

### Ідеї: одне питання до вас
- Для нового відео Claude спершу придумує **три ідеї**. Першою йде рекомендована, одна з трьох — сміливіша. По кожній: назва, головна думка, платформа й тривалість, перші 2 секунди, сюжет, вигляд і звук, що потрібно від вас.
- Потім ставить одне питання: яка підходить — A, B чи C. Відповідайте коротко: «бери A», «A, але фінал із C», «ще варіанти» чи «зміни …».
- Після вашого «так» Claude робить відео до кінця без зайвих питань.
- Усі ідеї записуються в `ІДЕЇ.md`: обрані, відкладені й відхилені. До відкладених можна повернутися.
- Етап ідеї пропускається, коли ідея вже є: ви дали готову ідею, сценарій чи бриф; написали «одразу роби», «без питань» або «на твій вибір»; це правка чи нова версія наявного відео.

### Сценарії
- Для відео довше ~15 с, яке щось розповідає, після вибору ідеї Claude пише `videos/<назва>/СЦЕНАРІЙ.md` за шаблоном `СЦЕНАРІЙ-шаблон.md`. У ньому:
  - погоджена ідея;
  - розкадровка: час, кадр, текст, голос, звук, скіл;
  - технічний паспорт із числами.
- Друге погодження не потрібне: після сценарію Claude одразу робить відео.
- Через `/script` або фразу «спершу сценарій» Claude зупиняється після сценарію й чекає вашого вибору. Потім напишіть «бери A» чи «зміни …», і він зробить відео.
- Голос додається лише на ваше прохання. Найкраще звучить ваш власний запис у `assets/`. Безкоштовний варіант — локальний синтез української (Piper), платні сервіси — лише з вашого дозволу.

Для складного відео заповніть `БРИФ-шаблон.md` (скопіюйте його) і передайте шлях: `/video assets/мій-бриф.md`.

## 3. Отримайте результат
- **Готове відео:** `output/<дата-назва>.mp4`, 1920×1080 (або 1080×1920 для Reels/Shorts), **60 fps**. Наступні версії мають у назві `-v2`, `-v3`, старі не перезаписуються. Графіка поверх уже знятого відео (B-roll, субтитри) отримує fps того відео.
- **Редаговані вихідники:** `videos/<дата-назва>/`.
- **Що зроблено, які рішення прийняті й що далі:** `ПІДСУМКИ.md`.

Правки пишіть звичайним текстом, наприклад «зроби текст більшим, а кінець на 2 с довшим». Claude змінить вихідники й зробить нову версію.

## Коли Claude спитає дозволу
- Перед платними діями (HeyGen, платні API).
- Перед видаленням або перезаписом файлів і перед публікацією, зокрема `git push`.
- Перед будь-яким встановленням поза папкою проєкту.

Перший запуск `/promo` або `/broll` поставить Playwright і Chromium (~150 МБ) у папку проєкту (`node_modules/`, `.cache/`). Вони не потрапляють у git.

## Важливо
- Великі відео в `assets/` git бачить. Перед `git push` переконайтеся, що файли менші за 100 МБ, або додайте їх у `.gitignore`.
- Ключі API зберігайте тільки в `.env`, цей файл уже в `.gitignore`.
