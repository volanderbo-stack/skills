# Як підключити проєкт «Motion Video» у вкладці Chat

1. **Інструкції.** Відкрийте проєкт → «Інструкції» (Instructions) → вставте весь текст з `1-інструкції-проєкту.txt`.
2. **Знання.** Проєкт → «Знання» (Files / Project knowledge) → завантажте файли з `2-знання/` і ваші бренд-матеріали (лого, кольори, шрифти).
3. **Скіли (необов'язково).** Скіли в Chat підключаються для всього акаунта, не для одного проєкту: Settings → Capabilities → Skills → Upload skill, по одному `.zip` з `3-скіли-zip/`. Також увімкніть там виконання коду (Code execution) і доступ до мережі, інакше скіли не зможуть рендерити.
   - `remotion-best-practices.zip` уже містить усі 12 скілів Remotion.
   - HyperFrames: `hyperframes`, `hyperframes-cli`, `hyperframes-registry`, `media-use`.
   - Barty-Bart: `explainer-high-energy` (промо), `motion-broll`, `sound-effects`.

## Чого очікувати
- У Chat Claude працює в хмарній пісочниці. Короткі ролики там часто вдається зрендерити, але важкі рендери (Remotion, промо 60 fps, B-roll з довгим відео) можуть не вкластися в обмеження.
- Повний рендер завжди працює в Claude Code у папці `Downloads\skills` (команди `/promo`, `/motion`, `/broll`, `/sfx`, `/subtitles`, `/video`). Інструкції Chat-проєкту вже кажуть Claude віддати вам вихідники й команди, якщо в Chat рендер неможливий.
